# 9주차 상관·회귀분석

Auto MPG 데이터(연비, 배기량, 마력, 무게, 가속)로 연비를 예측하는 회귀모델을 만든 과제입니다.
실습에서 전체 데이터로 다중회귀를 하면 마력의 계수가 양수(마력이 높을수록 연비가 좋음)로 나와 상식과 맞지 않았는데,
데이터를 그려 보니 마력 45 부근에서 두 그룹으로 나뉘어 있었습니다. 그래서 **마력이 45 이하인 데이터만** 골라 다시 모델링했습니다.

| 파일 | 내용 |
|---|---|
| `HW_regression_202310823.m` | 마력 45 이하 데이터로 단계적 선택(stepwise) 회귀모델을 만들고 오차 지표 계산 |

## 코드 흐름

1. `find(DATA(:,3) <= 45)`로 마력이 45 이하인 행을 고름
2. 설계행렬 `A`를 만들고 마지막 열에 1을 추가 (절편)
3. `stepwiselm(A, y)`로 유의한 항만 단계적으로 선택
   → 선택된 항: 절편, x1(배기량), x2(마력), x3(무게), x1·x3(교호작용)
4. 선택된 항에 맞춰 추정 연비 `y_est`를 계산하고 실제 연비와 산점도로 비교
5. 오차 지표 계산: MAE, %error, RMSE

## 실행 방법

강의에서 제공한 `auto-mpg_ex.csv`(1열 연비, 2~5열 배기량·마력·무게·가속)를 같은 폴더에 두고 MATLAB에서 실행합니다.
