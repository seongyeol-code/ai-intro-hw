# 12주차 퍼셉트론

붓꽃(iris) 데이터로 **퍼셉트론**을 직접 구현해 본 Python 코드입니다.
수업 참고 파일을 바탕으로 붓꽃 데이터를 **50개(setosa 25 + versicolor 25)**로 늘려 학습했습니다.

| 파일 | 내용 |
|---|---|
| `WK12_iris_perceptron.py` | 가중합 → 계단 함수로 −1/+1을 판정하는 퍼셉트론 클래스, 퍼셉트론 학습 규칙으로 w·b 학습, 특징 조합별 결과 비교, 새 꽃 판정 |

## 해 본 것

- 정답은 setosa = −1, versicolor = +1
- 퍼셉트론 = 앞 절반(가중합 `s = w·x + b`, 선형회귀와 같은 부분) + 뒤 절반(계단 함수 `s ≥ 0 → +1`)
- 학습 규칙: 틀렸을 때만 `w ← w + η(t − y)x`, `b ← b + η(t − y)`, 한 에폭 동안 틀린 샘플이 없으면 멈춤
- 학습률 η = 0.01, 최대 50 에폭으로 세 가지 특징 조합을 비교

| 사용한 특징 | 수렴까지 | 정확도 |
|---|---|---|
| 4개 (SL, SW, PL, PW) | 8 에폭 | 100% (50/50) |
| 꽃잎 2개 (PL, PW) | 2 에폭 | 100% (50/50) |
| 꽃받침 2개 (SL, SW) | 12 에폭 | 100% (50/50) |

꽃잎 정보만으로도 두 품종이 가장 쉽게 나뉘었고, 꽃받침 정보만 쓰면 수렴까지 더 오래 걸렸습니다.
마지막으로 학습한 4특징 모델로 새 꽃 3송이를 판정했습니다.

## 실행 방법

```bash
python WK12_iris_perceptron.py
```
(표준 라이브러리만 사용하므로 별도 설치가 필요 없습니다.)
