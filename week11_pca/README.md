# 11주차 차원축소 (PCA) 기초

PCA의 출발점인 **공분산 행렬**을 직접 계산해 본 Python 코드입니다. (강의자료 12, 14쪽 실습)
각 열에서 평균을 뺀 데이터 X로 공분산 행렬을 구하고, NumPy의 `np.cov` 결과와 같은지 확인했습니다.

| 파일 | 내용 | 결과 |
|---|---|---|
| `WK11_practice1.py` | 10×2 데이터에서 C = XᵀX / n (n으로 나눔), `np.cov(ddof=0)`와 비교 | [[0.0105, 0.0040], [0.0040, 0.0056]] |
| `WK11_practice2.py` | 점 (1,2), (2,6), (3,9), (5,12)에서 표본 공분산 C = XᵀX / (n−1), `np.cov(ddof=1)`와 비교 | [[2.9167, 7.0833], [7.0833, 18.25]] |

- 공분산 행렬의 대각선은 각 변수의 분산, 나머지 칸은 두 변수의 공분산입니다.
- `ddof=0`은 n으로, `ddof=1`은 n−1로 나눕니다.

## 실행 방법

```bash
python WK11_practice1.py
python WK11_practice2.py
```
(NumPy 필요)
